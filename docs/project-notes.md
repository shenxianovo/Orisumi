我在做一个事情：

## 背景

1. 模型能力稳步提升，但是模型对你的理解并没有增加（除非你进入到了模型的训练数据，成为了权重的一部分，但是你仍然需要特定的提示词引导来让模型激活对于你的理解）
2. Agent能接管人类的部分越来越多：工作，演示，汇报，编码，甚至饮食，健康，医疗。很多事Agent在当下都能做了。但是这些里面，和你想要的可能只有部分重合。也就是说，Agent需要和人类对齐，或者说至少需要能够观测到这个人以及这个人产生的信息
3. 人产生的信息散落在各个地方：可以是浏览器的浏览历史，也可能是某个平台的收藏夹，可以是我们现在进行的这段会话，也可能是短信，Slack，Telegram等IM里面的消息；甚至可以是玩某款游戏在游戏中的行为，以及物理世界中的身高体重，心率，睡眠时间，步数与运动轨迹，存款，股市，加密货币等财富状况.... 能补充的远不止这些
4. 那么我想要有一种方法或者有一个地方，能让Agent获取到这些信息，我想做的就是这个。

## 需求

1. 采集人的信息
2. 让Agent能利用这些信息
3. 对这些数据做一些可视化以便人能看

## 问题

1. 整个链路怎么建模，需不需要一个统一的Schema之类的东西，规范采集字段，标识各种不同东西的身份。还是各自只管自己的内容
2. 怎么采集
3. Agent怎么用，可视化怎么做
