# 发心：否决和待定

确认的陈述在文档站 `src/Docs/Orisumi.Docs/content/docs/requirements/belief.mdx`，这里用那里的名字引用。

## 否决

- 数字主权（曾作为发心候选）。用户：形式上有点像，但强调个人数字主权格局太大，不是发心。
- 讲述作为单独的一类（2026-11-03）。用户：IM 里发给自己的、对 Claude Code 说的、写进备忘录的，都由各自的来源采集，只要知道是这个人发的就行。讲述是一种视图，已写进「同一份数据多种视图」。

## 待定的问题

- Orisumi 会不会主动请人讲述，例如 Agent 问「那天为什么改了方向」？用户：先不定。
- 评测。换了模型重新生成理解后，要由人判断新的一版是不是更好，而人的注意力有限。评测材料已经有了，是测量基准 `.scratch/modeling/benchmark.md`。还没定的是怎么比新旧两版，助手的候选：人只看新旧两版的差异，不从头读。等加模型读出时再定。
