## 当前实现与证据

### 保存与取回

Codex 的日志原字节、state_5 整库一致快照、已选附件目录和直接出处已实现。真实采集包含 1,981 个普通文件、142 个链接、1,602,517,392 字节；本机整轮恢复、单文件导出与独立核对通过。变化版本、来源消失和部分失败由确定性样例覆盖。方法与范围见[Codex 验收](../../../src/Docs/Orisumi.Docs/content/docs/model/validation.mdx#codex-取得与恢复)。

日志、附件与数据库分别取得；采集根记录本轮起止窗口，清单记录取得方式。逐文件独立时间和跨材料共同快照仍未建立。模型与图中的实现说明已按这一实际范围更新。

### 外部副本

真实保存集已经复制到另一台 Linux 机器。2,888 个存储文件、1,159,911,553 字节与本机逐项 SHA-256 一致；独立读者恢复全部 1,981 个文件、142 个链接、1,602,517,392 字节，SQLite quick_check 通过。

外部工具先复制 config/records，再复制 blocks；全部引用校验通过后写完成记录并发布版本目录。当前存储只追加、根最后发布且没有 GC，这个顺序形成完整闭包。并发新增、删除事实、源不可用、缺块和损坏样例均已验证，具体口径见[外部副本验收](../../../src/Docs/Orisumi.Docs/content/docs/model/validation.mdx#外部副本)。

当前是一次手动备份，未配置计划任务、服务或保留期清理。后续新增材料等下一次备份；旧备份要合并最新可得删除事实才知道后来的删除。加入回收、改写或新依赖记录后重新验证复制顺序。

### 前台观测

macOS 小型原生程序取得 AppKit 通知与公开属性，托管采集器把每条完整观察行立即存成 Raw 记录。当前 macOS 手动应用级路线已在授权下由 Agent 采用并实现；三个专用应用的 7 次约 1 秒切换与 15 次约 0.2 秒切换全部实际完成，22 条激活与 22 条失活分别与应用自身回调的 PID、次数、各类别顺序和单应用内部顺序一致。

本轮 49 条原件包含 started、initial snapshot、46 条应用通知与 stopped，序号连续，全部恢复。独立核对哈希、长度、LF、来源、取得方式、运行身份与序号通过，共 46,150 字节。同应用 4 次真实切窗和 1 次标题修改期间没有新增应用级通知，说明当前接口的应用级范围。

22 个切换区间的 workspace 通知均先交付新应用激活、再交付旧应用失活；其中 21 次测试应用间切换的自身回调先失活、后激活。产品原件保存 workspace 的实际交付顺序，测试应用自身回调作为独立对照材料；observedAt 表达读取回调的时刻，应用启动日期与保存窗口分别保留。

定时结束与真实 TTY Ctrl+C 已验证。后者返回 130，保存并恢复 started/snapshot/stopped 三条、共 1,436 字节，stopped 原因是 stop-requested，采集根无失败。9 项前台行为测试覆盖逐条可读前缀、原字节、半行与异常、有效行失败回存、存储不可写、超时和原生 SIGINT；开发工具的 2 项新回归覆盖取消后收尾输出和超时强停。公开证据统一见[前台验收](../../../src/Docs/Orisumi.Docs/content/docs/model/validation.mdx#前台观测)。

本轮按 codebase-design 与 improve-codebase-architecture 检查了平台对象读取、进程运行循环、原字节交付及保存职责。Swift → JSONL → 托管原件存储的 seam 能定位并分别验证平台接收与保存问题，生产架构保留现状。

网络限制试验的两轮对照均确认普通 loopback 连接成功、同策略 deny network* 连接返回 EPERM。两次真实 orisumi run 均在开发启动/构建阶段等待至 120 秒终止，未进入采集、未创建存储；第二次关闭 MSBuild 与共享编译服务后仍相同，等待根因尚未定位。因此 local-first 继续有条件采用，真实受限采集与恢复链路仍待验证；现有证据只定位到开发入口的等待，采集是否依赖网络仍由实际采集样本判断。测试进程与监听均已清理，系统网络设置保持原状。

### 存储对照

五组聚合结果、唯一原文字节与压缩体积、元数据口径和通用复现方法集中在[整文件与分块对照](../../../src/Docs/Orisumi.Docs/content/docs/model/validation.mdx#整文件与分块对照)。真实静态集整文件压缩更省，大日志中部插入回放 CDC 更省；回放与真实连续历史分开。原始样本、逐文件清单和完整实验输出仅本机保留，公开图引用正式摘要。

## 本轮解决的卡点

| 问题 | 当前处理与验证 |
| --- | --- |
| 图的实现字段仍称没有 Codex、没有恢复命令或 ADR3 采用网状 | 按代码、现行模型与验收重写 43 处实现说明，外部副本与前台分别保留准确完成范围 |
| 前台沿周期扫描会留下未提交窗口 | 每条完整观察立即形成独立采集根；已有前缀可恢复，进程停止和未落地尾部的缺口分别说明 |
| 有效观察在存储失败后回存时被误称为无效，计数遗漏 | 最小失败用例先复现，再修正路径与已保存计数；未知/半行仍按对应失败材料保留 |
| TTY Ctrl+C 先杀掉进程树，正常结束行来不及保存 | 原生程序由父进程 stdin 收尾，产品取消窗口与 Dev 有界等待相配合；真实 TTY 及进程行为回归通过 |
| stdin 提前关闭掩盖已取得半行的错误 | 双管道关闭回归保留两种失败事实与已取得末尾字节 |
| 静态查询与管道测试不足以证明真实切换可取得 | 受控应用自身记录真实激活/失活，独立与 22 次切换及 49 条恢复原件对账；清理旧桌面状态阻塞表述 |
| 不同回调通道的跨应用交错次序不同 | 保留 workspace 实际交付顺序，按激活、失活各类别和每个应用内部顺序分别核对，来源时间与取得时间分别说明 |
| 网络限制试验停在开发入口，尚未进入实际采集 | 网络拒绝对照已验证；两次 orisumi run 在启动/构建阶段等待至 120 秒终止，未生成存储，根因待定位。local-first 保持条件性，不影响已通过的当前前台路线采用 |
| 公开证据链接指向被忽略的本机目录 | 统一改引正式 validation 页，公开聚合结果与方法，样本和私密运维值留在本机忽略目录 |
| 先复制内容再复制新增记录可能缺块 | 确定性反例定位缺失清单；先 records 后 blocks 的并发试验和真实异机恢复通过 |
| 只拿早期备份无法知道后来的删除 | 明确旧副本的时间范围，合并最新完整记录后核对正常列举不复活已删除采集 |
| 浏览器工具拒绝 file 协议 | 保留实际布局未验收的限制；以无浏览器 DOM 测试核对交互逻辑 |

## 图与方法检查

图生成器检查文件引用、节点唯一、关系无环、候选终点、确认字段、采用候选与显式冲突。本轮重建后重新执行图验证、全图 DOM 测试以及本地链接与标题锚点检查。DOM 覆盖导航、搜索、单选/多选、路线载入、试选导出、采用状态/阶段筛选和确认/采用隔离；实际浏览器布局另待验证。

qstack 的方法试跑是有限场景：自主展开已有独立例子，新增“授权后自主采用并实现”的独立 Agent 行为试跑尚未执行。结构检查与真实对话效果分别判断。项目级 tidy/verify 由主 Agent 合并后统一执行，图检查不替代产品验收。

## 尚待补充的证据

- **长期自动取得**：当前命令内循环与手动备份已经可用，登录启动、定时副本和长期运行还需实际安排与检验。
- **长期保存**：独立异机恢复证明当前格式可解释、依赖可取得；定期演练、断电和十年介质寿命仍需对应证据。
- **理解与身份**：原件引用与恢复已成立；语义读出、数据库行定位、跨源身份、模型调用包和版本选择继续按真实问题进入。
- **他人使用与共享**：自己的第二保存位置与给其他人看材料分别处理；真实受众、范围和交付产物出现时再验授权。
