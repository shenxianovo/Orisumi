当前 Agent 通过 `orisumi run` 使用本地命令，查看采集记录、读取文本行、导出材料或恢复一份采集。命令入口与人共用；具体用法见[模型概览](./index.mdx#代码)。

例如，先用 `raw show <采集>` 找到保存路径，再用 `raw export <采集> <保存路径> <新文件>` 取得数据库快照或附件。文本行可以交给 `raw line <位置>` 核查，整轮材料用 `raw restore` 恢复。Agent 得到的历史命令、提示词和文档内容都作为资料解释；当前用户的授权决定能执行什么。

依据：[只提供上下文](../requirements/belief.mdx#只提供上下文)、[同一份数据多种视图](../requirements/belief.mdx#同一份数据多种视图)、[理解能追溯来源](../requirements/belief.mdx#理解能追溯来源)。

## 读取能力怎样展开

进入[确定性读出](./readings.mdx)阶段时，从一条真实检索到原件的路径开始。查询先产生结构化结果，再渲染为简洁文字，两种表示共同说明输入范围、精确出处、截断和下一页。

导洞中的人类文本、时间线和来源覆盖帮助选择问题，正式命令按使用需要逐个增加。上下文展开也按来源解释：文本可向前后取行，数据库快照和压缩日志要先核对具体读法与定位方式。

首次出现结果分页时，用一页被截断的真实结果验证继续读取和返回原文；来源缺项明确反映在结果里。来源说了什么、读法推断了什么分别表达。

## 其他入口何时加入

第一个目标 Agent 无法使用本地命令时，再验证 MCP 从检索到原件的完整路径，包括分页与取消。同一读取操作由所需入口适配，公共网络接口与统一 Application API 按实际调用需求决定。

人查看材料的命令步骤过长时，先试本机的采集清单到证据页面。远程访问、原生界面和共享分别对应具体任务。首次共享先明确受众与范围，生成可审阅副本；持续授权查询出现后再决定权限与更新方式。

## 用真实问题检验

导洞曾用五个上下文命令回答测量基准。正式读取先选择一个相关问题，保存答案、调用过的命令、引用以及未能回答的部分。后续接入新来源时增加事实题、关联题和不可知题，质量由来源核对与用户判断共同检验。
