---
title: "给 Agent 的命令"
description: "Agent 拿上下文的五个命令"
---

Agent 只通过 `orisumi run context` 下的五个命令拿关于这个人的上下文。输出是给 Agent 读的文本，每行末尾的方括号里是原件里的[位置](./raw.mdx#位置)，可以交给 `around` 和 `raw` 往下追。

依据：

- [只提供上下文](../requirements/belief.mdx#只提供上下文)：Orisumi 给 Agent 提供关于这个人的上下文，行动留给 Agent。
- [同一份数据多种视图](../requirements/belief.mdx#同一份数据多种视图)：Agent 是首要读者，每项能力不开界面也能调用，原件 Agent 也能直接读。
- [理解能追溯来源](../requirements/belief.mdx#理解能追溯来源)：每个结论都能指回原件里的那一行。

| 命令 | 输出 | 读的是 |
| --- | --- | --- |
| `sources` | 每次采集的采集记录；每台设备、每种数据的覆盖和丢失 | 采集记录、覆盖 |
| `timeline [--from] [--to] [--device] [--kind] [--min-seconds]` | 各台设备上的时段 | 时间线 |
| `said [--from] [--to] [--grep]` | 人说的话，带会话标题和工作目录 | 人说的话 |
| `around <位置> [--before] [--after]` | 原件里这一行前后的记录，读成文本 | 原件 |
| `raw <位置>` | 原件里的这一行，原样 | 原件 |

时间参数是本地时间，例如 `2026-10-30` 或 `2026-10-30T18:00`，`--to` 是开区间。`timeline` 默认隐藏短于 60 秒的时段，提交总是显示，输出开头写明隐藏了几条。三种读出的说明见[读出](./readings.mdx)。

## around

`around` 按位置打开原件文件，从这一行往前读 10 条、往后读 20 条，`--before`、`--after` 可以改。会话日志的每条记录读成一行：人说的话、注入的内容、助手的回复、工具调用的名字和参数、工具结果，长内容截断并标出截掉的长度。其他来源的行原样显示。

`around` 直接按原件里的位置往前后读，会话怎么划分留给 Agent 从前后文判断。

依据：[一件事散在多处](../requirements/belief.mdx#一件事散在多处)：勘探发现 rewind、子 Agent 和续接文件会把一段会话复制或分到好几个文件里，按某一种会话划分先切开，会丢掉其余的组织方式。

## 用答题检验

导洞用一个只能运行这五个命令的 Agent 检验模型：在空目录里起 `claude -p`，只开放 Bash，只允许运行一个转发到 `orisumi run context` 的脚本，按测量基准逐题作答。答案和它调用过的命令一起存下，由用户判断答得好不好。
