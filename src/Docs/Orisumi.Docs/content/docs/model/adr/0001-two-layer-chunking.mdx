---
title: "0001 完整材料、定位器与物理块分开"
description: "采集端交付完整材料，存储负责切块，细定位随读法增加"
---

当前采用完整材料与独立定位器：采集端按来源交来一次读取的文件字节、数据库快照或一批事件，存储按内容切成物理块，再按清单恢复。文本先用行号，压缩日志、数据库快照和二进制附件先引用整份材料。需要内部定位的读出上线时，再用一个真实样本确定带类型和版本的定位器。

这样既能保留来源原来的表示，也能让切块器只承担存储和恢复。采集时按语义结构拆材料会把解析选择固化进原件；细定位随读法形成，已有字节和取得事实继续保留。

切块器属于存储格式，版本与参数写进文档和采集记录。当前沿用 `orisumi-cdc-1`；只有连续版本的占用或读取成本形成实际问题时，才用同一批真实材料比较其他切法。读取现有原件只依赖清单中的块顺序。
