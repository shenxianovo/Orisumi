---
title: "0004 模型处理启用时保留调用事实"
description: "先做确定性读取；系统内模型处理由真实题目触发"
---

读取阶段先由程序取已知字段和原文，把语义理解交给使用材料的 Agent。确定性读出反复遇到需要语义解释的题目时，再固定输入比较系统内模型处理的质量与费用。当前采集和恢复先保持独立。

正式模型处理一旦启用，每次保留实际发送内容、工具往返、返回结果和直接取得的运行信息。相同输入的多次输出各自保留；有两个正式理解版本或人工纠正时，显式记录采用哪版，并验证可以恢复该选择。模型未返回的内部过程保持未知。

这会增加调用材料和版本管理的成本，但使结果能回到当时实际发生的调用。先用两次真实调用核对保存范围，再确定记录格式与读出表示；复制方式沿实际采用的副本路线选择。
