---
title: "0009 历史按查询区间细分"
description: "保留同刻条目，不用返回的最后访问时间推进游标"
---

历史接口限制单次返回量；实测同一时刻的三个 URL 可以被限量截掉，而窗口内旧访问对应的 `lastVisitTime` 又可能在窗口外。采用固定时间范围的二分细化，在一毫秒内仍饱和时增加限量；原数组长度用于判断饱和，原响应完整保存。相比返回时间游标，这会增加重复搜索，但不会因同刻条目或窗口外最新时间主动越过尚未取得的查询区间。

这条路线取得接口可见视图，每个请求各自有时间和出处；遍历结束记录实际错误与未解决区间。来源库还有接口未列出的行与字段，因此完成标记表达请求计划结束，覆盖结论按[来源证据](../browser-persistent.mdx#证据能说明什么)解释。
