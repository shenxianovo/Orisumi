---
title: "0003 副本先验证外部备份"
description: "先验证已完成保存内容的完整备份与恢复，再按真实需要评估节点"
---

当前采用外部完整备份作为下一步副本路线。收集与恢复可以先独立交付，外部工具负责复制已完成的保存内容；验证时让原目录不可用，再核对记录引用的内容是否齐全、损坏能否检出。

这一选择先承担备份闭包与恢复验证的成本。应用内节点同步会增加交换进度、断线重连和多处删除的责任，当前先由实际复制或跨设备查询需要触发它们。若外部工具直接复制写入中的存储无法得到完整副本，就先固定一份记录及其内容再备份。

外部恢复通过后，真实跨设备查询或复制问题出现时先比较单个常开入口；设备直接交换确实有收益时再评估网状拓扑。备份保留期内可能仍有逻辑删除的字节，恢复时按保存的删除事实决定可见内容。
