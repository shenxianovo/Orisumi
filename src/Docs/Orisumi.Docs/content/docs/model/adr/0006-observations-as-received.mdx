---
title: "0006 系统观测按取得事实逐条保存"
description: "系统对象先忠实记录，每个收到的完整观察行立即存成原件"
---

macOS 前台应用接口交来通知和应用对象。当前采用小型原生观察程序，将通知名称、应用对象的公开属性、实际取得时间和本次运行内的顺序忠实写成观察行；Orisumi 保存这些行的原始字节。初始查询、系统通知和程序生命周期分别标明，应用切换的含义与活动时段留给后续读出。

每个收到的完整观察行立即独立提交为一份采集记录。这样，程序中途停止时，已经提交的前缀可以取回；代价是每条观测带来小型内容、清单和采集记录。等实际文件数量或写入成本形成问题，再比较持久追加与封批。先在内存等一批再存，会让未提交的观测随进程消失。

原生程序负责平台对象、通知和运行循环，托管采集器负责取得原始行、保存结果和子进程退出。当前没有引入所有来源共用的事件框架，也没有用文件采集的轮询间隔代替系统通知。观察程序未运行期间和尚未提交的末尾仍可能缺失；这些界限随证据说明。
