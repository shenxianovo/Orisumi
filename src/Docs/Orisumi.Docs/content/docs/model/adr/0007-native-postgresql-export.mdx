title: "0007 旧库按本人范围保留原生文本导出"
description: "用显式查询取得本人历史，保存模式、COPY 文本与来源条件"
---

旧 Heartbeat 混合保存多个所有者的材料。采用同一只读快照中的本人查询，保留 PostgreSQL 原生 text COPY、准确模式和取得条件，再交给现有文件采集保存。这样，归档离开旧服务后仍有明确的字段解释和恢复方式。

二进制 COPY 在实际一天样本中能完整恢复；文本样本多 20.27% 的正文，换来对类型二进制布局更少的依赖。接受这项体积代价，保留来源直接交付的文本原字节，以及版本、编码、时间表示、列顺序和类型。长期恢复仍需核对实际字段和数据库版本。[PostgreSQL COPY 格式与限制](https://www.postgresql.org/docs/18/sql-copy.html#SQL-COPY-NOTES)

`pg_dump` 的对象选择不能直接表达本次本人行范围，因此采用显式查询和独立关联核对。先完成一次有出处的历史保存；持续采集器的价值由后续更新频率和取得成本决定。具体范围与验收见[旧 Heartbeat 历史](../heartbeat.mdx)。
