---
title: "0002 位置精确指向一次取得"
description: "采集记录根、材料路径与定位器保留精确出处"
---

位置以采集记录根的内容哈希作为取得身份，再带材料路径与适用的定位器。当前文本行写成 `<来源>/<采集记录>/<文件>:<行号>`，存完整名字，显示前 12 个十六进制字符；输入接受至少 8 位且唯一的前缀。压缩文件、数据库快照和附件通过采集记录与保存路径指向整份材料。

同一内容出现在多个路径或多次采集里，每次取得都有独立出处。读出以后可以据证据建立代表关系，并展开全部出处；精确引用保持原来的采集锚点。被引用的采集逻辑删除后，引用报告失效。

内容哈希识别字节，采集记录识别取得事实，来源自己的身份继续保存在原件里。只用时间作取得身份会受时钟与同一时刻重复采集影响；只用内容哈希则会丢掉相同字节的不同出处，所以三者分开表达。
