## 为什么验证 [#why]

模型回答问题时先搜索再读原文，搜索范围错了会读到工具输出或自己说过的话。约定见 [Reading · 搜索](../../api/reading.mdx#search)。

## 前置条件 [#setup]

通过真实 API 和独立的 PostgreSQL 数据库运行，见 [测试分工](../index.mdx#kinds)。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 搜索一段出现在 `searchable` 字段中的文字 | 返回这份 Observation |
| 这段文字只出现在没有声明 `searchable` 的字段中 | 不返回 |
| 这段文字只出现在助手交互的工具输出或注入的上下文中 | 不返回 |
| 嵌套在数组元素中的 `searchable` 字段，例如 `parts[].text` | 返回 |
| 带 `from`、`to`、`resourceName` 和 `thingId` | 条件一起生效 |
| 带 `speakerId` 或 `excludeSpeakerType=models` | 只返回或排除模型的话 |
| 被否定的 Observation 含这段文字 | 默认不返回，`view=all` 返回 |
| 缺少 `q` 或 `q` 为空 | 400 |
| 用 limit=1 沿 next 翻页 | 各页与完整结果一致 |
| 中文和英文，大小写不同 | 按子串原样比较 |
