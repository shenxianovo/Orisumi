export const caseId = 'api-same-as';

## 为什么验证 [#why]

两个事物不合并，全靠读取时展开，图表要跟着变。约定见 [Same-As](../../core/model/same-as.mdx)。

## 前置条件 [#setup]

通过真实 API 和独立的 PostgreSQL 数据库运行，见 [测试分工](../index.mdx#kinds)。准备两个设备事物 A、B，各有前台时段。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 写一条 A、B 的 Same-As，按 A 查询 `GET /observations?thingId=` | 返回 A 和 B 的 Observation |
| `GET /things/{A}` | `sameAsThingIds` 含 B，`state`、`relations` 和 `activity` 都包含 B 的 |
| A 和 B、B 和 C 各一条 Same-As，按 A 查询 | 返回 A、B、C 的 |
| Same-As 的事实时间是 10 月，查询 10 月和 11 月 | 10 月的 B 被展开，11 月的 B 不展开 |
| 否定这条 Same-As | 按 A 查询只返回 A 的，两个 `thingId` 和已有的引用都不变 |
| 否定 Same-As 的一段时间 | 其余时间仍然展开 |
| 写一条左右对调的 Same-As，再否定原来的一条 | 命题按无序的一对比较，两条都不生效 |
| 查询引用方 | 不展开 |
