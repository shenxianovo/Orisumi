## 为什么验证 [#why]

用户操作的是对象，对象视图不用认识具体的业务类型就要分对。约定见 [Reading · 对象视图](../../api/reading.mdx#thing-view)。

## 前置条件 [#setup]

通过真实 API 和独立的 PostgreSQL 数据库运行，见 [测试分工](../index.mdx#kinds)。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 事物有 Name，以 `about` 只引用它 | 在 `state` 中，`thing.name` 是默认视图中的名字 |
| Relation 以 `about` 引用它和另一个事物 | 在 `relations` 中 |
| 一份 Observation 以 `about` 引用它，以 `mention` 引用另一个事物 | 在 `state` 中 |
| 一种类型以 `part` 引用它，另一种以 `mention` 引用它 | `activity` 各一项，写资源名、角色和数量 |
| 同一类型有 `part` 和 `mention` 两种引用 | `activity` 各一项 |
| 用 `href` 请求 | 分页列出这一项，数量与 `count` 相同 |
| 引用方有被否定和被替换的 | 不在 `state`、`relations` 中，也不计入 `count` |
| 状态类型有两条同一状态的陈述 | `state` 中取一条 |
| 事物已删除或从未出现 | 分别为 410 和 404 |
| 事物没有任何引用方 | 三个数组都为空，`name` 为 `null` |
