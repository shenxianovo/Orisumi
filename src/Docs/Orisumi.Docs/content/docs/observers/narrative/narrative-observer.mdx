叙事 Observer 程序实例是一个事物。它用这份描述说明自己，见 [OBSERVER-9](../../core/model/observer.mdx#observer-9)，它写下的每件事都通过 `observerVersionId` 引用描述的一个版本。

<ObserverStructure node="NARRATIVE" />

## 粒度 [#granularity]

一份描述对应一个程序实例。每个部署一个，见 [Narrative · 程序实例](./index.mdx#instance)。

## 身份 [#identity]

EntityId 由后端保存，API 重启和升级后沿用，见 [OBSERVER-4](../../core/model/observer.mdx#observer-4)。程序版本或模型型号变化时，形成描述的新版本，所以每件事都能查到当时用的模型。

## EntitySchema [#schema]

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-000000000017` |
| 显示名称 | 叙事 Observer |
| 说明 | 描述一个叙事 Observer 程序实例：它的程序版本和调用的模型。 |
| 资源名 | `narrative-observers` |
| `kind` | `observation` |
| `immutable` | `false` |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `programVersion` | `string` | 是 | 否 | 程序的版本 |
| `model` | `string` | 是 | 否 | 写叙事时调用的模型，写作供应商和型号，例如 openai/gpt-6.1-terra |

## 示例 [#example]

```json
{
  "programVersion": "0.1.0",
  "model": "openai/gpt-6.1-terra"
}
```
