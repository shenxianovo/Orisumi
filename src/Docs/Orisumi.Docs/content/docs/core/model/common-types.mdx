这些业务类型由 Core 定义，后端内置，所有 Observer 不用声明就能使用，读取方都能理解。[Review](./review.mdx)、[Same-As](./same-as.mdx) 和 [Adoption](./adoption.mdx) 也是内置的，它们的语义由后端理解，各有自己的类型页。

## Relation [#relation]

模型发现的关系，例如“QQ 号 123 是本人”。关系不用预先定义类型，软件要用来计算的关系才单独定义，例如线索归属。

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-00000000000f` |
| 显示名称 | 关系 |
| 说明 | 表示两个事物之间的一种关系。事实时间是这个关系成立的时段。 |
| 资源名 | `relations` |
| `claimFields` | `subjectId`、`predicate`、`objectId` |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `subjectId` | `reference`，目标为事物，`role` 为 `about` | 是 | 否 | 关系的主语 |
| `predicate` | `string`，`searchable` | 是 | 否 | 关系的说法，例如“是本人” |
| `objectId` | `reference`，目标为事物，`role` 为 `about` | 是 | 否 | 关系的宾语 |
| `text` | `string`，`searchable` | 是 | 是 | 补充说明 |

## Name [#name]

事物的名字：设备名、产品名、会话标题和人的称呼都用它。来源、模型和用户都可以写。

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-000000000010` |
| 显示名称 | 名字 |
| 说明 | 表示一个事物的名字。事实时间是这个名字成立的时段，未知时为 null。 |
| 资源名 | `names` |
| `stateFields` | `thingId` |
| `claimFields` | `thingId`、`name` |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `thingId` | `reference`，目标为事物，`role` 为 `about` | 是 | 否 | 被命名的事物 |
| `name` | `string`，`searchable` | 是 | 否 | 名字的原文 |

## Observer 描述 [#observer-descriptions]

程序实例和 Agent 说明自己，见 [OBSERVER-9](./observer.mdx#observer-9)。每个 Observer 有自己的一串描述，后一份替换前一份。

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-00000000001c` |
| 显示名称 | Observer 描述 |
| 说明 | 描述一个程序实例或 Agent：运行的平台、主机名、程序版本和调用的模型。事实时间未知。 |
| 资源名 | `observer-descriptions` |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `platform` | `string` | 是 | 否 | 运行的平台，例如 `macos`、`linux` |
| `hostName` | `string` | 是 | 是 | 本机的名称，读不到时为 `null` |
| `programVersion` | `string` | 是 | 否 | 程序的版本，即安装包的版本 |
| `model` | `string` | 是 | 是 | 调用的模型，写作供应商和型号，例如 `openai/gpt-6.1-terra`。不调用模型时为 `null` |
| `decisionModel` | `string` | 是 | 是 | 分两步判断时，在选项中选择所调用的模型，写法相同。没有这一步时为 `null` |

```json
{
  "platform": "linux",
  "hostName": null,
  "programVersion": "0.1.0",
  "model": "openai/gpt-6.1-terra",
  "decisionModel": "openai/gpt-6-luna"
}
```
