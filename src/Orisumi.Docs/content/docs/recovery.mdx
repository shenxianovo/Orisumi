分析前一天的数据，先查各来源的观测依据，再关联事实：

```sh
orisumi capture coverage --from 2026-11-13T00:00:00+08:00 --to 2026-11-14T00:00:00+08:00
```

命令只读五个来源的 `capture_coverage` 视图，返回与半开区间 `[from,to)` 相交的记录；缺库返回 `no_database`。记录保留原区间，不裁剪到查询边界。

| 字段 | 含义 |
| --- | --- |
| `scope` | 事实或通道范围 |
| `mode` | `replay` 日志/历史补读，`notification` 通知，`snapshot` 当前值采样 |
| `started_at_utc_ms` / `stopped_at_utc_ms` | 此项依据的时间范围；同值为一个时点，空结束表示未确认 |
| `evidence` / `detail` | 读取结果、可用性、运行状态或缺口及上下文 |
| 来源附加列 | 运行 ID、浏览器配置等，用于库内关联 |

日志记录实际读取起止；浏览器历史的 `range_read` / `read_failed` 记录来源查询范围，按 URL 最后访问时间选取；通知通道记录本地可用性变化，网络记录采样区间。各项依据的时间含义由来源与 `evidence` 共同确定。

这些记录不能合并成一个“全程完整”的布尔值。通知后读取现值只能证明该次观测，无新事实本身不证明状态未变；未确认结束不能用重启或查询结束时间补齐。

## 恢复边界

| 来源 | 可恢复内容 | 无法补齐的内容 |
| --- | --- | --- |
| Claude / Codex 日志 | 从已提交完整行继续；重放按记录身份去重 | 来源已删除的记录；追加同时改写未检查的已读中段 |
| Codex 数据库 | 重读会话、回合、消息现值 | 两次读取之间的中间修订 |
| 浏览器 | 重放持久队列、回填保留的访问记录；其他事实重建初值 | 入队前丢失的事件、浏览器已清理的历史和离线中间状态 |
| macOS | 恢复通道后重新订阅、建立初值 | 中断期间的切换、输入及未观察到的释放 |
| 网络 | 新快照建立计数基线 | 采样间隙短连接和中断期间的精确增量 |

日志增量读取以追加为前提，用文件身份、长度、修改时间和首尾检查点识别替换、截断与重写；不是任意文件改写的版本历史。

输出库重建前停止对应采集器，重建后重启；浏览器代码更新另需重载扩展。来源保留的历史重新回填，事件来源重新建立初值。具体事实与调度见[采集数据](./sources.mdx)，网络增量边界见[设备网络采集](./network.mdx)。
