## 本地运行

文档站位于 `src/Orisumi.Docs`，需要 Node.js 24.14 或更新版本。

在仓库根目录运行：

```sh
orisumi dev docs install
orisumi dev docs
```

打开 [本地文档站](http://127.0.0.1:3020/docs)。

## 编写内容

文档放在 `src/Orisumi.Docs/content/docs`，使用 Markdown 或 MDX。
每个页面通过 frontmatter 声明 `title` 和 `description`，相邻页面使用相对文件路径链接。
同一目录的 `meta.json` 控制侧栏顺序。

需要固化设计时，先把目标、依据和取舍讨论清楚，再把当前有效的结论写入对应页面。

## 页面历史

`fumadocs-page-history` 在构建时读取当前仓库的 Git 历史，自动在页面末尾显示贡献者和提交记录，历史列表默认展开。
新文件首次提交前没有历史页脚。只发生 Git 提交而正文没有变化时，重启开发服务以刷新记录。

构建环境需要完整的 Git 历史；使用 GitHub Actions 时，checkout 设置 `fetch-depth: 0`。

## 检查与构建

```sh
orisumi dev docs check
orisumi dev docs build
orisumi dev docs start
```

`start` 启动已构建的站点，默认使用本地端口 3020。运行前先停止占用该端口的开发服务。
