description: Chrome 的访问记录、标签和窗口、下载和书签。
---

扩展转发 Chrome 的通知和定时快照，接收端与库里的最后已知状态比较后写入，流程见[架构](../../overview/architecture.mdx#各来源怎么走)。标签和窗口每分钟一次快照，下载和书签每五分钟一次，历史每分钟补读一段。只采普通窗口：隐身窗口、标签和下载在扩展里就过滤掉，聚焦到隐身窗口时普通标签的焦点结束。

`profile_id` 是这次扩展安装生成的随机 ID，卸载重装会变。扩展拿不到 Chrome 配置本身的身份，是不是同一个配置在派生层判断。`browser_session` 区分 Chrome 的一次启动，标签和窗口 ID 只在其中有效。

扩展和接收端是同一个组件，构建时把组件版本写进扩展的 `version_name`。扩展连上时在 `open` 里报告它，接收端记进 `browser_runs.extension_version`，并回复自己的版本；两者不同时让扩展 `chrome.runtime.reload()`，Chrome 从磁盘重新加载新文件。扩展在 `chrome.storage.local` 里记下已为哪个接收端版本重载过，同一版本只重载一次；仍不一致就照常连接，覆盖里记为 `extension_version_mismatch`。没有 `version_name` 的构建（测试）不报版本，也不会被要求重载。

## 访问记录

| 事实或视图 | 含义 |
| --- | --- |
| `visits` | Chrome 保留的访问：时间、URL、跳转类型、引荐访问（`''` 表示没有）、是否本机产生 |
| `history_page_title_observations` / `history_pages` | 每个 URL 读取时看到的标题的初值和变化／最新标题；不是访问当时的标题 |

历史按 URL 的最近访问时间分段读，每个 URL 读出 Chrome 还保留的全部访问。读到哪和访问记录在同一事务提交。Chrome 已经清掉的历史补不回来。

## 标签和窗口

| 事实或视图 | 含义 |
| --- | --- |
| `tabs` / `browser_windows` | 标签、窗口身份 |
| `tab_observations` | 一次通知或快照；同一次的事实共享 `observation_id` |
| `tab_presence_events` / `window_presence_events` | 存在的初值、出现和关闭 |
| `tab_url_observations` / `tab_title_observations` | URL、标题各自的变化；空为 `''`，读不到为 NULL |
| `tab_window_observations` | 标签在哪个窗口；拖出窗口还没放下时 `has_window=0`。不记标签条里的位置 |
| `browser_window_focus_events` / `window_active_tab_events` | 聚焦的 Chrome 窗口／每个窗口的当前标签。`has_window`、`has_tab` 为 0 表示明确没有，为 NULL 表示未知 |
| `active_tab_focus` | 按 `observation_id` 合并窗口焦点和当前标签的变化，推导观测后的前台标签 |
| `tab_history` / `current_tabs` | 每次变化后每个标签的完整状态／最后已知打开的标签 |

## 下载

| 事实或视图 | 含义 |
| --- | --- |
| `downloads` / `download_observations` | 下载身份、URL、开始时间／每次观测 |
| `download_response_observations` | 最终 URL、总大小、MIME；不记进度 |
| `download_state_observations` / `download_path_observations` | 状态和完成时间／本地路径，各自变化 |
| `download_history` / `current_downloads` | 每次观测后的状态／最后已知状态 |

通知没带的字段沿用上次的值。从下载列表移除不代表文件被删。

## 书签

| 事实或视图 | 含义 |
| --- | --- |
| `bookmarks` / `bookmark_observations` | 节点身份、种类、创建时间／每次观测 |
| `bookmark_presence_events` / `bookmark_title_events` / `bookmark_url_events` | 存在、名称、目标 URL；文件夹没有 URL |
| `bookmark_location_events` | 所在文件夹的变化；不记文件夹里的顺序 |
| `bookmark_last_used_observations` | Chrome 记的最后使用时间，来自快照，列不出每次使用 |
| `bookmark_state` / `current_bookmarks` / `bookmark_history` | 含已删除节点的最新状态／当前存在的节点／每次观测后的状态 |

删除文件夹时，已知的子孙节点一起记消失。

## 投递

扩展的待发队列按序号投递，接收端提交后才确认，重发不会重复入库。格式不对、永远写不进去的投递连同原文和错误存进 `browser_rejected_deliveries` 后确认出队，覆盖里记为 `delivery_rejected`；暂时的失败留在队列里退避重试。
